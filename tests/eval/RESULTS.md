Generated by `tests/eval/report.py` from `tests/eval/out/*.results.json`.

## What this measures (and what it does not)

- A tiny pinned task set (4 math, 5 multiple-choice, 2 generation), **greedy decoding, one sample per item**. Accuracy moves in coarse steps (one item = 20-25%) and the deltas are noisy.

- These are **not** the paper's numbers. The paper's AIME pass@1 uses 30 problems and 16 samples; the paper values below are a direction/scale reference, not a pass/fail bar.

- `LoopCD-Hidden` is meaningful only on `f32_clean` (f32 weights + f32 KV). On the shipping stack (`Q4_K_M` + `q8_0`) it is known to degenerate to a repeating token, so the shipping `hidden` row is reported for honesty, not as a reproduction.

- Conditions: `off`; `logits` (fixed omega from the paper's per-task preset); `logits_adaptive` (paper cap); `hidden` (fixed omega = 0.5).
